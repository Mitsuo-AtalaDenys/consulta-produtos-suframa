FORMAS DE PESQUISA
Para pesquisar qualquer PALAVRA, basta inserir o termo desejado.
EXEMPLO: Portaria.
Para pesquisar uma EXPRESSÃO, basta digitar o termo desejado ENTRE ASPAS DUPLAS.
EXEMPLO: FRASE: “autorização de pesquisa” NÚMEROS (CPF,CNPJ...): “000.000.000-00”.
Para PESQUISA FONÉTICA, informe uma palavra que tem a mesma pronúncia apesar de estar grafada de maneira distinta.
EXEMPLO: Marcus/Marcos; Sousa/Souza; infra-estrutura/infraestrutura.
